# Patoo404 portfolio

Rance Ashriel R. Sabino's static cybersecurity portfolio with Hack4Gov Jeopardy CTF review notes.

## GitHub Pages

Repository: azzzriieell00.github.io

In Settings > Pages, choose Deploy from a branch, main, and /(root), then Save.

The portfolio will be available at https://azzzriieell00.github.io/ after GitHub completes deployment.

The site uses plain HTML, CSS, and JavaScript. No build command or dependencies are needed.

Open index.html with VS Code Live Server to preview locally. Click Security lab to open the reviewer.

## Edit the site

- index.html: introduction and education
- portfolio-data.js: projects, social links, and tech stack
- styles.css and app.js: portfolio appearance and behavior
- security-lab.html, lab.css, lab.js: reviewer page and controls
- lab-notes.js and hack4gov-review.md: review content and matching offline download
- assets/rance-sabino.jpg: profile image

Keep .nojekyll in the repository root so GitHub publishes these files directly.
